A considered data boundary.

The prototype code makes no network requests and uses no account, analytics, backend, or browser storage. Choices stay in page memory and clear when you reload. Please don’t enter personal or sexual-history details.

The public host may receive ordinary connection data when this page is served; this source-level check is not a privacy or security audit. The page is not monitored and cannot respond to a crisis. Human-support and emergency guidance require qualified review before participant use.
